# Kell Electricals: homepage redesign concepts

Two homepage directions for kellelectricals.com, kept separate from the live site
(`Kellelectric/Googlesitesitemap`). Nothing here affects the live site.

| Route | Concept |
|---|---|
| `/` | Index of both concepts |
| `/daylight` | Option A: light and warm, after the Daylight energy site |
| `/t1` | Option B: dark and premium, after the T1 Energy site |

Brand: petrol `#13322C`, Energy Yellow `#F5B700`, Inter. Copy, figures and reviews are
taken from the live site and Google reviews; the comparison table and FAQ questions are
placeholders to review. Photos are the live site's licensed Unsplash photos (credits in the
main repo's `docs/photo-credits.md`); real job photos should replace them before launch.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
